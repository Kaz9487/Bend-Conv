# Contributing

[English](CONTRIBUTING.md) | [繁體中文](CONTRIBUTING.zh-TW.md)

Thank you for your interest in Bend-Conv.

## Questions and bugs

Open an [issue](https://github.com/Kaz9487/Bend-Conv/issues). For a bug, include the program or command, what you expected, what happened, and your Bend version and operating system.

## Changes

1. Fork the repository and create a topic branch.
2. Set up the tools as in [getting started](docs/getting_started.md).
3. Make the change, and update the documents that describe it.
4. Run the checks:

   ```sh
   python run.py layout
   python run.py proofs
   python run.py api
   ```

5. Open a pull request that says what changed and why.

[Development](docs/development.md) lists every command, the repository layout and the rules a change follows.
